# tachimanga-repo

Dépôt d'extensions Tachimanga (généré automatiquement par `tachimanga-ext-ehentai/build.sh`, ne pas éditer à la main).

URL à ajouter dans Tachimanga → Réglages → Extensions → Extension repositories → Add (essayer la 1re, sinon la 2e) :

```
https://raw.githubusercontent.com/AmitSanZaza/tachimanga-repo/main
https://raw.githubusercontent.com/AmitSanZaza/tachimanga-repo/main/index.min.json
```

Contenu : `repo.json` (+ `index.pb`, format Keiyoushi 2026) et `index.min.json` (ancien format), `apk/`, `jar/`, `icon/`.
